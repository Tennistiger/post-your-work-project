# Project Overview

This project explores bikeshare data from Chicago, New York City, and Washington. Users can filter the data by city, month, and day to generate statistics.

## Files used

bikeshare.py
chicago.csv
new_york_city.csv
washington.csv

## Requirements

Python 3
Pandas
NumPy

## Example Usage

Run the program from the terminal:
python bikeshare.py

## Installation

Download the project files.
Place the CSV files in the project directory.
Run bikeshare.py using Python.
